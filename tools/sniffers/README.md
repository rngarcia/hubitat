# Sniffers

Diagnostic drivers used to reverse-engineer Tuya Zigbee data points. They are not listed in HPM.

- `zemismart-sdm02t-sniffer.groovy`: logs the raw DPs of the Zemismart SDM02T energy meter.
- `tuya-zigbee-valve-sniffer.groovy`: logs the raw DPs of Tuya/GiEX Zigbee irrigation valves.

Install one manually (Drivers Code → New Driver → paste), switch the device to it temporarily, read the logs, then switch back.
