# Hikvision Audible Alarm Trigger (ISAPI) — Hubitat driver

[![Buy me a beer](https://img.shields.io/badge/Buy%20me%20a%20beer-PayPal-f5a623?logo=paypal&logoColor=white)](https://www.paypal.com/donate/?business=rngarcia%40gmail.com&currency_code=USD)

Triggers the built-in audible alarm (siren/voice) on Hikvision cameras over ISAPI, locally.

## Installation

**Hubitat Package Manager:** Install → Search by Keywords, search for `Hikvision Audible Alarm Trigger (ISAPI)`. Or Install → From a URL with:
`https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/hikvision-audible-alarm/packageManifest.json`

**Manual:** Drivers Code → New Driver → Import, paste `https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/hikvision-audible-alarm/hikvision-audible-alarm.groovy` and Save. Later updates use the same **Import** button.
