# Remotec ZXT-120 IR Extender — Hubitat driver

Modified Z-Wave driver for the Remotec ZXT-120 IR extender, used to control air conditioners.

Based on the work of Bryan Copeland (djdizzyd).

## Installation

**Hubitat Package Manager:** Install → Search by Keywords, search for `Remotec ZXT-120 IR Extender`. Or Install → From a URL with:
`https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/remotec-zxt-120/packageManifest.json`

**Manual:** Drivers Code → New Driver → Import, paste `https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/remotec-zxt-120/remotec-zxt-120.groovy` and Save. Later updates use the same **Import** button.
