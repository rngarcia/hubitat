# Tuya Zigbee Water Level Sensor — Hubitat driver

> **Not maintained.** This driver is no longer in HPM and I no longer use it. For this sensor, use [kkossev's Tuya Zigbee Tank Level Monitor](https://github.com/kkossev/Hubitat/tree/main/Drivers/Tuya%20Zigbee%20Tank%20Level%20Monitor), which covers the same device. The code stays here for reference.

Zigbee driver for the Tuya ultrasonic water-tank level sensor (_TZE200_lvkk0hdg): level, distance, water column height.

## Installation

**Manual only:** Drivers Code → New Driver → Import, paste `https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/tuya-zigbee-water-level/tuya-zigbee-water-level.groovy` and Save.
