# Heiman HS2WD-E Siren — Hubitat driver

[![Buy me a beer](https://img.shields.io/badge/Buy%20me%20a%20beer-PayPal-f5a623?logo=paypal&logoColor=white)](https://www.paypal.com/donate/?business=rngarcia%40gmail.com&currency_code=USD)

Zigbee driver for the Heiman HS2WD-E siren: alarm, strobe and tone control.

## Installation

**Hubitat Package Manager:** Install → Search by Keywords, search for `Heiman HS2WD-E Siren`. Or Install → From a URL with:
`https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/heiman-hs2wd-e-siren/packageManifest.json`

**Manual:** Drivers Code → New Driver → Import, paste `https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/heiman-hs2wd-e-siren/heiman-hs2wd-e-siren.groovy` and Save. Later updates use the same **Import** button.
