# Tuya Zigbee Water Level Sensor — Hubitat driver

[![Buy me a beer](https://img.shields.io/badge/Buy%20me%20a%20beer-PayPal-f5a623?logo=paypal&logoColor=white)](https://www.paypal.com/donate/?business=rngarcia%40gmail.com&currency_code=USD)

Zigbee driver for the Tuya ultrasonic water-tank level sensor (_TZE200_lvkk0hdg): level, distance, water column height.

## Installation

**Hubitat Package Manager:** Install → Search by Keywords, search for `Tuya Zigbee Water Level Sensor`. Or Install → From a URL with:
`https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/tuya-zigbee-water-level/packageManifest.json`

**Manual:** Drivers Code → New Driver → Import, paste `https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/tuya-zigbee-water-level/tuya-zigbee-water-level.groovy` and Save. Later updates use the same **Import** button.
