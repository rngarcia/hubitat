# GiEX Irrigation Valve (sh1btabb) — Hubitat driver

> **Not maintained.** This driver is no longer in HPM and I no longer use it. For GiEX and other Tuya Zigbee valves, use [kkossev's Tuya Zigbee Valve](https://github.com/kkossev/Hubitat/tree/main/Drivers/Tuya%20Zigbee%20Valve), which covers the same device. The code stays here for reference.

Dedicated Zigbee driver for the GiEX irrigation valve _TZE200_sh1btabb: irrigation timing, water consumed and running totals. Based on kkossev's Tuya Zigbee Valve.

Based on the work of Krassimir Kossev (kkossev, Tuya Zigbee Valve v1.7.1).

## Installation

**Manual only:** Drivers Code → New Driver → Import, paste `https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/giex-irrigation-valve/giex-irrigation-valve.groovy` and Save.
