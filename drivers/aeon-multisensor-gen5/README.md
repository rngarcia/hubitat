# Aeon Multisensor Gen5 — Hubitat driver

Fixed Z-Wave driver for the Aeon Multisensor Gen5 (motion, temperature, humidity, illuminance, battery).

Based on the work of keltymd.

## Installation

**Hubitat Package Manager:** Install → Search by Keywords, search for `Aeon Multisensor Gen5`. Or Install → From a URL with:
`https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/aeon-multisensor-gen5/packageManifest.json`

**Manual:** Drivers Code → New Driver → Import, paste `https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/aeon-multisensor-gen5/aeon-multisensor-gen5.groovy` and Save. Later updates use the same **Import** button.
