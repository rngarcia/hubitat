# GiEX Irrigation Valve (sh1btabb) — Hubitat driver

[![Buy me a beer](https://img.shields.io/badge/Buy%20me%20a%20beer-PayPal-f5a623?logo=paypal&logoColor=white)](https://www.paypal.com/donate/?business=rngarcia%40gmail.com&currency_code=USD)

Dedicated Zigbee driver for the GiEX irrigation valve _TZE200_sh1btabb: irrigation timing, water consumed and running totals. Based on kkossev's Tuya Zigbee Valve.

Based on the work of Krassimir Kossev (kkossev, Tuya Zigbee Valve v1.7.1).

## Installation

**Hubitat Package Manager:** Install → Search by Keywords, search for `GiEX Irrigation Valve (sh1btabb)`. Or Install → From a URL with:
`https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/giex-irrigation-valve/packageManifest.json`

**Manual:** Drivers Code → New Driver → Import, paste `https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/giex-irrigation-valve/giex-irrigation-valve.groovy` and Save. Later updates use the same **Import** button.
