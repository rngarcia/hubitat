# Zemismart SDM02T Energy Meter — Hubitat driver

[![Buy me a beer](https://img.shields.io/badge/Buy%20me%20a%20beer-PayPal-f5a623?logo=paypal&logoColor=white)](https://www.paypal.com/donate/?business=rngarcia%40gmail.com&currency_code=USD)

Zigbee driver for the Zemismart SDM02T 2-phase energy meter (Tuya), built from DP sniffing: per-phase voltage, current, power and energy.

## Installation

**Hubitat Package Manager:** Install → Search by Keywords, search for `Zemismart SDM02T Energy Meter`. Or Install → From a URL with:
`https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/zemismart-sdm02t/packageManifest.json`

**Manual:** Drivers Code → New Driver → Import, paste `https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/zemismart-sdm02t/zemismart-sdm02t.groovy` and Save. Later updates use the same **Import** button.
