# Aeon Smart Dimmer 2nd Edition — Hubitat driver

Z-Wave driver for the Aeon Labs Smart Dimmer 2nd Edition (DSC25), ported from SmartThings' metering dimmer.

Based on the work of SmartThings (zwave-metering-dimmer.groovy, Apache 2.0).

## Installation

**Hubitat Package Manager:** Install → Search by Keywords, search for `Aeon Smart Dimmer 2nd Edition`. Or Install → From a URL with:
`https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/aeon-smart-dimmer-2nd/packageManifest.json`

**Manual:** Drivers Code → New Driver → Import, paste `https://raw.githubusercontent.com/rngarcia/hubitat/main/drivers/aeon-smart-dimmer-2nd/aeon-smart-dimmer-2nd.groovy` and Save. Later updates use the same **Import** button.
